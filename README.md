# Production DevSecOps Platform

A production-oriented DevSecOps project demonstrating the complete lifecycle of a containerized microservices application running on Amazon EKS.

## Project Goals

- Build and containerize a microservices application
- Provision AWS infrastructure using Terraform
- Deploy workloads to Kubernetes
- Implement CI using GitHub Actions
- Implement GitOps delivery using Argo CD
- Secure the software supply chain
- Manage application secrets securely
- Implement metrics, logs, traces and alerts
- Test scalability, resilience and recovery
